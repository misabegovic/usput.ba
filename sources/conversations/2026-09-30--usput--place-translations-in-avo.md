# Place translations in Avo, 2026-09-30

Before building the places page in the admin, the agent asked two questions,
one at a time.

1. Which languages curators may edit by hand in the Avo places page. The
   options were Bosnian and English with the rest read-only, Bosnian only,
   or all 16. Answer: "All 16 languages".
2. What a later AI retranslation should do with a translation a curator
   edited by hand. The options were to keep hand edits, to let the AI
   overwrite them, or to ask each time. Answer: "Ask each time": the
   retranslate action lists the hand-edited languages and the curator
   chooses which to overwrite.
